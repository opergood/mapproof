# mapproof — MapProof 외부판 관리

이 저장소는 **MapProof 외부 배포판**을 관리합니다. (코드가 아니라 '허가목록·버전'만 둡니다.)

## allow.json — 쓸 수 있는 PC 정하기
- 외부판을 쓰는 PC 에서 [설정] → [PC 등록 정보] 를 열면 **PC 번호**가 나옵니다.
- 그 번호를 `allow` 목록에 넣으면 그 PC 에서 외부판이 열립니다.
- 목록에서 빼면, 그 PC 는 다음에 열 때 막힙니다. (인터넷이 돼야 확인합니다.)

예:
```json
{ "allow": ["A1B2C3D4E5F60718", "0011223344556677"] }
```

## version.json — 새 판 알리기
- 새 외부판을 낼 때: 설치 파일을 이 저장소에 올리고(이름 `MapProof_설치_외부_최신.exe`), `version` 을 새 판 번호로 바꿉니다.
- 외부판은 열릴 때 이걸 보고, 더 새 판이면 받아서 깝니다.
